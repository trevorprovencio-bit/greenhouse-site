# Greenhouse website

The site for Greenhouse, a tattoo shop, hair salon and art space at 15 Zillicoa St in Montford, Asheville. Dre and Chuck Donoghue run it.

These pages were moved over from the design comps on the Greenhouse canvas in Claude (the "Website" page). It is plain HTML and CSS with no build step.

## Run it

Open `index.html` in a browser, or serve the folder:

```
npx serve .
```
